# Сравнительный анализ и поиск лучших формул

## Когда применять

Протокол применяется, когда задача имеет несколько возможных методов
решения или подходов. НЕ применяется для простых справочных запросов
(определение, дата, ссылка).

## Уровни активации

- **Уровень 1 (лёгкий)**: 2–3 подхода, краткое сравнение в абзаце.
  Для типовых задач (план урока, карточка).
- **Уровень 2 (средний)**: 3–5 подходов, таблица сравнения, рекомендация
  лучшего. Для нетривиальных задач (проектная работа, программа внеурочки,
  система оценивания).
- **Уровень 3 (глубокий)**: полный бенчмаркинг с анализом методической
  литературы, сравнение по 5+ критериям, выявление лучшей формулы.
  Для сложных методических задач (рабочая программа с нуля, система
  оценки, адаптация ОВЗ).

## Алгоритм сравнительного анализа

1. **ИДЕНТИФИКАЦИЯ АЛЬТЕРНАТИВ** — определи 2–5 альтернативных методов:
   а) методическая литература и ФОП (подходы федеральной программы);
   б) педагогические технологии: проблемное и проектное обучение, развитие
      критического мышления, blended learning, flipped classroom,
      геймификация, CASE-технология, технология мастерских;
   в) разные УМК и их методические подходы;
   г) разные формы организации: фронтальная, групповая, парная, индивидуальная;
   д) разные цифровые инструменты и ЭОР.

2. **ОЦЕНКА ПО КРИТЕРИЯМ**:
   - Соответствие ФГОС (требования к результатам, содержанию).
   - Соответствие СанПиН (плотность, нагрузки, время).
   - Методическая эффективность (достижение целей урока).
   - Возрастная адекватность (доступность, мотивация).
   - Практическая реализуемость (время подготовки, ресурсы).
   - Гибкость (адаптация под разный уровень класса).
   - Цифровая поддержка (наличие верифицированных ЭОР).

3. **СРАВНИТЕЛЬНАЯ ТАБЛИЦА** (для уровня 2 и 3):

   | Подход | ФГОС | СанПиН | Эффективность | Возраст | Реализуемость | Гибкость |
   |---|---|---|---|---|---|---|
   | А | +/- | + | ... | ... | ... | ... |
   | Б | + | + | ... | ... | ... | ... |
   | В | + | - | ... | ... | ... | ... |

4. **ВЫБОР ЛУЧШЕЙ ФОРМУЛЫ** — на основе сравнения определи лучшую формулу:
   - Формула = оптимальная комбинация методов для конкретного класса,
     предмета и условий.
   - Укажи: почему именно эта формула лучше в данном случае.
   - Если нет однозначного лидера — предложи 2 варианта с условиями выбора
     («Если класс сильный — подход А, если смешанный — подход Б»).

5. **КОНТРАСТИВНЫЙ АНАЛИЗ** (для уровня 3):
   - Чем выбранный подход лучше альтернативы?
   - Что теряется при выборе альтернативы?
   - В каких условиях альтернатива могла бы быть лучше?
   - Devil's Advocate: почему выбранная формула может не сработать?

6. **РЕКОМЕНДАЦИЯ** — итог в 1–3 предложениях: лучшая формула,
   при необходимости — альтернативная, условия переключения.

## База лучших формул (Memory-of-Thought)

Накапливай и обновляй формулы решений для типовых задач. При длительном
использовании храни базу в MCP `memory` (граф знаний), чтобы формулы
сохранялись между сессиями.

**Формула 1: Урок открытия нового знания (5–9 класс)**
Проблемная ситуация → выдвижение гипотез → проверка через ЭОР →
конструирование правила → первичное закрепление (3 уровня) → рефлексия →
дифференцированное ДЗ.
Лучше для: сильных и средних классов.
Альтернатива для слабых: объяснение → демонстрация → поэтапное
закрепление → рефлексия.

**Формула 2: Урок обобщения и систематизации (7–11 класс)**
Кластер/схема понятий → групповая работа (станции) → взаимопроверка по
критериям → индивидуальный тест → коррекция → рефлексия.
Лучше для: повторения перед контрольной.
Альтернатива: лабиринт знаний (игровая форма).

**Формула 3: Проектный урок (9–11 класс)**
Погружение в проблему → формулировка исследовательского вопроса →
планирование (SMART) → сбор данных (ЭОР + самостоятельный поиск) →
анализ → оформление продукта → защита → рефлексия.
Лучше для: индивидуальных проектов.

**Формула 4: Адаптация материала для ОВЗ**
Упрощение лексики → визуальная поддержка (пиктограммы, схемы) → дробление
на микро-шаги → многократное повторение → сниженный объём заданий →
эмоциональная поддержка → альтернативная форма контроля.
Лучше для: обучающихся с лёгкими нарушениями.
Альтернатива для тяжёлых: индивидуальный маршрут по ФАОП.

**Формула 5: Формирующее оценивание**
Критерии в начале → самооценка по критериям → взаимооценка →
обратная связь учителя → коррекция → переоценка.
Лучше для: текущего контроля.
Альтернатива: тест с автоматической проверкой через ФГИС.

**Формула 6: Урок с дорогим/недоступным оборудованием (5–9 класс)**
Проблемный вход («Почему соль исчезает в воде?») → короткая
демонстрация учителя → виртуальная лаборатория/ЭОР ЦОК на каждый стол →
закрепление 3 уровней → рефлексия → дифференцированное ДЗ.
Лучше для: предметов с лаб. оборудованием, которого нет на каждый стол
(естествознание, физика, химия), сильных и средних классов.
Альтернатива (нет проектора): демонстрация + карточки с опорой на РЭШ
(эффективность ниже ~15–20%).
Источник: тест v6 2026-09-19, запрос «Свойства воды».

При каждом новом запросе дополняй базу формул, если обнаружил новую
эффективную комбинацию методов.

## Антипаттерны сравнительного анализа

- НЕ сравнивай ради сравнения: если очевиден один подход — укажи его
  и упомяни альтернативу кратко.
- НЕ перегружай ответ таблицами для простых задач.
- НЕ предлагай подходы, нарушающие ФГОС/СанПиН.
- НЕ игнорируй условия пользователя: класс, уровень, ресурсы.
- НЕ описывай методы, нереализуемые в типовой школе без спецоборудования
  (если пользователь не указал, что оно есть).
