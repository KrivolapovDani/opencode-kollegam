# Установка — пошагово (простой язык)

Всё займёт 10–15 минут. Ничего сложного: скрипт делает почти всё сам.

## Что нужно заранее

1. **Windows 10/11** — компьютер.
2. **opencode** — программа, в которой работает помощник. Если её нет, установите:
   - откройте PowerShell и выполните: `npm install -g opencode-ai`
   - (или спросите у того, кто дал вам этот комплект)
3. **GitHub-аккаунт** — бесплатный. Если нет: зайдите на github.com и создайте (2 минуты).

## Шаг 1. Скачайте комплект

- Нажмите зелёную кнопку **Code** → **Download ZIP** (или скопируйте репозиторий, если умеете).
- Распакуйте ZIP в любую папку, например `C:\Users\<ваше имя>\Documents\opencode-kollegam`.

## Шаг 2. Запустите установку

- Откройте PowerShell (Пуск → наберите `powershell` → Enter).
- Перейдите в папку комплекта:
  ```
  cd C:\Users\<ваше имя>\Documents\opencode-kollegam
  ```
- Запустите скрипт:
  ```
  powershell -ExecutionPolicy Bypass -File .\install.ps1
  ```
- Скрипт сам: скопирует промты и скилы, настроит opencode, проверит вход в GitHub.

## Шаг 3. Войдите в GitHub (один раз)

- Если скрипт попросит — откроется браузер, подтвердите вход.
- Или выполните сами: `gh auth login --web` → выберите GitHub.com → HTTPS → подтвердите в браузере.

## Шаг 4. Запустите opencode

- Выполните: `opencode`
- Выберите агента: **teacher** (педагог-методист) или **developer** (разработчик).
- Скажите: **«самоанализ»** — помощник проверит себя и подключится к общей базе ошибок.

## Шаг 5. Готово

Работайте как обычно. Помощник сам будет:
- забирать чужие ошибки из общей базы;
- добавлять туда свои (когда ошибка устранена);
- напоминать об обновлениях комплекта.

## Как обновить комплект

Повторно запустите `install.ps1` — он обновит промты, скилы и базу ошибок.

## Если что-то не получилось

Напишите тому, кто дал вам комплект, — он поможет.
