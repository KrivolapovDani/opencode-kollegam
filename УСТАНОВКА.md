# Установка — пошагово (простой язык)

Всё займёт 10–15 минут. Скрипт делает почти всё сам. После установки
у вас будет **два помощника**: педагог-методист и разработчик
(переключение — клавиша Tab в opencode).

## Что нужно заранее

1. **Windows 10/11** — компьютер.
2. **opencode** — программа, в которой работает помощник. Если её нет:
   - откройте PowerShell и выполните: `npm install -g opencode-ai`
   - (или спросите у того, кто дал вам этот комплект)

Git и GitHub-аккаунт **не нужны** — скрипт всё скачает сам.

## Шаг 1. Скачайте комплект

- **Способ А (без GitHub-аккаунта).** Вставьте в браузер прямую ссылку на архив:
  ```
  https://github.com/KrivolapovDani/opencode-kollegam/archive/refs/heads/master.zip
  ```
  Скачается ZIP — распакуйте его в любую папку, например
  `C:\Users\<ваше имя>\Documents\opencode-kollegam`.
- **Способ Б (с сайта GitHub).** Нажмите зелёную кнопку **Code** → **Download ZIP**,
  распакуйте так же.

## Шаг 2. Запустите установку

- Откройте PowerShell (Пуск → наберите `powershell` → Enter).
- Перейдите в папку комплекта:
  ```
  cd C:\Users\<ваше имя>\Documents\opencode-kollegam
  ```
- Запустите скрипт:
  ```
  powershell -ExecutionPolicy Bypass -File .\install.ps1
  ```
- Скрипт сам: скопирует промты и скилы, настроит opencode (оба агента),
  скачает базу ошибок (через git, если он есть, или ZIP-ом — без git).

## Шаг 3. Вход в GitHub — по желанию

Вход нужен **только** тем, кто хочет обновлять комплект и базу ошибок
через git. Можно пропустить — установка от этого не сломается.

- Если скрипт откроет браузер — подтвердите вход или просто закройте окно.
- Или выполните сами: `gh auth login --web` → GitHub.com → HTTPS → подтвердите в браузере.

## Шаг 4. Запустите opencode

- Выполните: `opencode`
- Выберите агента: **teacher** (педагог-методист) или **developer** (разработчик).
- Скажите: **«самоанализ»** — помощник проверит себя и подключится к общей базе ошибок.

## Шаг 5. Готово

Работайте как обычно. Помощник сам будет:
- забирать чужие ошибки из общей базы;
- добавлять туда свои (когда ошибка устранена);
- напоминать об обновлениях комплекта.

## Установка без GitHub (полностью офлайн)

Если github.com недоступен или вы не хотите ничего качать из сети:

```
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Offline -SkipOshibki
```

- `-Offline` — пропускает вход в GitHub и git-операции;
- `-SkipOshibki` — не скачивает базу ошибок (ядро комплекта ставится полностью).

Базу ошибок можно подключить позже, когда появится доступ к сети:
просто запустите `install.ps1` ещё раз.

## Как обновить комплект

Повторно запустите `install.ps1` — он обновит промты, скилы и базу ошибок.

## Если что-то не получилось

Напишите тому, кто дал вам комплект, — он поможет.
