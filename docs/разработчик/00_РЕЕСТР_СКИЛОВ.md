## Протокол роста (кратко)

1. Агент предлагает новую технологию/паттерн/ошибку → обновить скил или создать новый.
2. Пользователь подтверждает → снапшот → правка → регрессия (≥11/12) → журнал авторегенерации → синхронизация по hash.
3. Критичные скилы (dev-guardrails) меняются только с явного OK.

Детали — раздел 3 `00_ПРАВИЛА_ПРОЕКТА.md`.
