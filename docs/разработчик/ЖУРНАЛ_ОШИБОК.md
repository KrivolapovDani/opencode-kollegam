# ЖУРНАЛ ОШИБОК — агент «Разработчик»

Правило: заметил свою ошибку по ходу работы (повтор, неверная команда,
потеря контекста, зацикливание, мусор) — запиши сюда СРАЗУ. Самоанализ
(dev-reflexion) проверяет этот журнал и предлагает устранение.

Формат записи:
- **Ошибка:** [что произошло]
  **Где:** [задача/файл/блок]
  **Причина:** [промт / скил / исполнение / контекст]
  **Статус:** [открыта | устранена | не воспроизводится]
