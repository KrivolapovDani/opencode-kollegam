## Как проверять целостность

```
Get-FileHash -LiteralPath "путь\к\файлу" -Algorithm SHA256
```

Хэш должен совпасть со строкой из таблицы. Расхождение — файл менялся
или повреждён при передаче; не используй такой пакет.
