# Резюме пакета «Разработчик v1.2»

**Версия:** v1.2 | **Дата:** 2026-09-20 | **Статус:** проверен, готов к использованию

## Что это

Облегчённый системный промт разработчика (v1.2) + 6 dev-скилов + MCP-серверы
для opencode. Агент `developer` умеет: Python (скрипты, автоматизация,
обработка данных), веб (HTML/CSS/JS/TS), PowerShell/автоматизация Windows,
Git и CI/CD, безопасность, обучение программированию, Office-документы
(docx/xlsx/pptx через officecli).

**Главная идея:** промт лёгкий (~4–5K токенов), вся глубина вынесена
в скилы, которые подгружаются по требованию. Контекст не забивается
справочниками, пока они не нужны.

## Что нового в v1.1 (анти-деградация)

- **Большие задачи по умолчанию:** ТЗ → блоки → цели → журнал (Шаблон 5).
- **Анти-зацикливание:** 3+ одинаковых попытки → стоп, чек-поинт, вопрос.
- **Уборка мусора** после задач (временные файлы, черновики, артефакты).
- **ЖУРНАЛ_ОШИБОК.md:** ошибки фиксируются по ходу работы, самоанализ
  проверяет и предлагает устранение.
- **Office-документы:** направление 7 (officecli, close при блокировке,
  batch через файл + `--input`, не убивать MCP-процесс).
- dev-checks: 41 → 42 проверки (G6 — нет мусора).

## Требования к получателю

- opencode (десктоп или CLI)
- Node.js LTS (для MCP memory и sequential-thinking)
- Python/uv (для MCP fetch и time) — по желанию, без них работает
- Интернет при первой установке MCP (npx скачивает пакеты)

## Установка за 4 шага (кратко)

1. **Скилы** → скопируй `03_скилы\` в `%USERPROFILE%\.config\opencode\skills\`.
2. **Конфиг** → вставь блоки `agent`, `skills.paths` и `mcp` из
   `opencode_developer.jsonc` в свой `opencode.jsonc`, заменив
   `ИМЯ_ПОЛЬЗОВАТЕЛЯ`.
3. **Агент** → перезапусти opencode, переключись на `developer` (Tab).
   Промт подтянется сам из `prompts\dev.txt` — вставлять ничего не нужно.
4. **Проверка** → дай 3 контрольных запроса (список в чек-листе, Шаг 4).

Подробности, частые вопросы и запасной вариант (ручная вставка) —
в `00_ЧЕК_ЛИСТ_УСТАНОВКИ.md`.

## Важно знать

- **Работает только в opencode.** v1.2 без скилов и MCP резко деградирует —
  для других ассистентов добавляй скилы вручную.
- **Память формул** хранится в `memory.jsonl` (настраивается через
  `MEMORY_FILE_PATH`) — не удаляй файл.
- **Работа блоками:** большие результаты ассистент выдаёт частями
  («Часть 1 из N» + чек-поинт). Пиши «продолжи» — он подхватит контекст.
- **Журнал ошибок:** заметил ошибку агента — она фиксируется в
  `ЖУРНАЛ_ОШИБОК.md`; самоанализ проверяет и предлагает устранение.
- **Регрессия:** после правок промта/скилов прогоняй контрольный набор
  (6 запросов, порог ≥ 11/12) — правило 19 dev-reflexion.
