# Пакет «Педагог-методист v6» — для передачи коллегам

**Версия:** v6.1 | **Дата релиза:** 2026-09-20 | **Статус:** проверен, готов к использованию

---

## Что это

Облегчённый системный промт педагога-методиста (v6) + 6 скилов + MCP-серверы
для opencode. Работает по ФГОС/ФОП/ФАОП/СанПиН/ФЗ-273, умеет составлять
рабочие программы, планы уроков, сравнивать методы, адаптировать материалы
для ОВЗ, проектировать внеурочку и системы оценивания.

**Главное отличие от v5:** промт стал в ~5 раз легче (≈4–5K токенов вместо
20–25K), вся глубина вынесена в скилы, которые подгружаются по требованию.
Качество ответов не упало — подтверждено тестами.

## Установка за 4 шага (кратко)

1. **Скилы** → скопируй `02_Скилы\` в `%USERPROFILE%\.config\opencode\skills\`.
2. **Конфиг** → вставь блоки `agent` и `mcp` из `opencode_config.jsonc`
   в свой `opencode.jsonc`, заменив `ИМЯ_ПОЛЬЗОВАТЕЛЯ`.
3. **Агент** → перезапусти opencode, переключись на `teacher` (Tab).
   Промт подтянется сам из `prompts\v6.txt` — вставлять ничего не нужно.
4. **Проверка** → дай 3 контрольных запроса (список в чек-листе, Шаг 4).

Подробности, частые вопросы и запасной вариант (ручная вставка) —
в `00_ЧЕК_ЛИСТ_УСТАНОВКИ.md`.

## Важно знать

- **Работает только в opencode.** v6 без скилов и MCP резко деградирует —
  для других ассистентов используй полный v5.
- **Память формул** хранится в `memory.jsonl` (настраивается через
  `MEMORY_FILE_PATH`) — не удаляй файл.
- **Нормативка устаревает ~каждые 90 дней.** Раз в четверть проси
  «обнови ссылки» — self-reflexion подскажет изменения.
- **СанПиН 1.2.3685-21** действует до 01.03.2027.
- **Работа блоками:** большие документы ассистент выдаёт частями
  («Часть 1 из N» + чек-поинт). Пиши «продолжи» — он подхватит контекст.
