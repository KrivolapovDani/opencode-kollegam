# opencode-kollegam — комплект промтов и скилов

Готовый комплект для работы в opencode: промты (педагог-методист и разработчик) + все скилы + скрипт установки.

## Что внутри

```
opencode-kollegam/
  README.md            ← этот файл
  УСТАНОВКА.md         ← инструкция для коллег (простой язык)
  install.ps1          ← скрипт установки (делает всё сам)
  prompts/
    dev.txt            ← промт разработчика
    v6.txt             ← промт педагога-методиста
  skills/              ← скилы (13 шт.)
```

## Для кого

Для коллег, которые хотят работать с opencode так же, как автор комплекта: методические разработки, презентации, документы, автоматизация.

## Как установить

Смотрите `УСТАНОВКА.md` — 5 простых шагов. Скрипт `install.ps1` сам скопирует промты и скилы, настроит opencode и подключит общую базу ошибок.

## Как обновляться

Повторно запустите `install.ps1` (или `git pull`, если клонировали репозиторий). Промт сам напомнит об обновлениях при запуске.

## Общая база ошибок

Отдельный репозиторий `oshibki-kollegam` — общая база ошибок всех коллег. Устанавливается автоматически. Добавляйте свои ошибки — это поможет всем.
