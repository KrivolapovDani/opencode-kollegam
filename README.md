# opencode-kollegam — комплект промтов и скилов (учитель + разработчик)

Готовый комплект для работы в opencode: **два агента по умолчанию** —
педагог-методист и разработчик — все скилы, скрипт установки.

## Что внутри

```
opencode-kollegam/
  README.md            ← этот файл
  УСТАНОВКА.md         ← инструкция (простой язык)
  install.ps1          ← скрипт установки (делает всё сам)
  prompts/
    dev.txt            ← промт разработчика (v1.2)
    v6.txt             ← промт педагога-методиста (v6.1)
  skills/              ← 13 скилов (6 разработчика + 6 учителя + officecli)
  configs/
    opencode_developer.jsonc   ← блок конфига агента «Разработчик»
    opencode_teacher.jsonc     ← блок конфига агента «Педагог-методист»
  docs/
    разработчик/       ← документация пакета разработчика (v1.2)
    учитель/           ← документация пакета учителя (v6)
```

## Для кого

Для коллег, которые хотят работать с opencode так же, как автор комплекта:
методические разработки, рабочие программы, презентации, документы,
автоматизация. Оба агента ставятся сразу — переключение клавишей Tab.

## Как установить

Смотрите `УСТАНОВКА.md` — 5 простых шагов. Скрипт `install.ps1` сам
скопирует промты и скилы, настроит opencode (оба агента) и подключит
общую базу ошибок.

## Как обновляться

Повторно запустите `install.ps1` (или `git pull`, если клонировали
репозиторий). Промт сам напомнит об обновлениях при запуске.

## Общая база ошибок

Отдельный репозиторий `oshibki-kollegam` — общая база ошибок всех коллег.
Устанавливается автоматически. Добавляйте свои ошибки — это поможет всем.
